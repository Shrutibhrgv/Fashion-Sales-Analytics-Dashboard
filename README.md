# Fashion Sales Analytics Dashboard (Excel)

## 📊 Project Overview
This interactive Excel-based Business Intelligence dashboard was built to analyze 31K+ retail transactional orders. The project demonstrates an end-to-end analytics workflow designed to solve core business questions regarding revenue trends, customer demographics, and channel performance.

To maintain professional standards, the workbook utilizes a robust **4-tier data architecture** rather than a single chaotic spreadsheet.

---

## 🏗️ Workbook Architecture
* **Tier 1: Index (Landing Page):** An application-style navigation UI with custom buttons and removed gridlines to optimize user experience.
* **Tier 2: Raw Data:** The untouched, open-source transactional data layer to ensure absolute data lineage and auditability.
* **Tier 3: Clean Data (ETL Layer):** The transformation tier where data cleaning (handling nulls, duplicates, and date standardization) took place alongside advanced formula-driven helper columns.
* **Tier 4: Business Insight Dashboard:** The final presentation layer driven by Pivot Tables, dynamic charts, customized number formatting, and cross-filtering slicers.

---

## 🎯 Business Questions Solved
* **Channel Optimization:** Which e-commerce platforms (Amazon, Flipkart, Myntra) generate the highest revenue and volume?
* **Regional Performance:** Which states are driving the core of our retail sales?
* **Fulfillment Efficiency:** What is the overall order delivery success rate vs. returns?
* **Demographic Segmentation:** Which customer profiles contribute the most to the bottom line?

---

## 🛠️ Tech Stack & Key Features
* **Data Cleaning:** Deduplication, formatting standardization, and error handling.
* **Formulas Used:** `VLOOKUP`, `IF`, `TEXT`, `GETPIVOTDATA`, and basic logical aggregations.
* **Visualization:** Dynamic Pivot Charts (Horizontal Bar charts, Donut charts), KPI Cards, and synchronized Slicers (Region, Category, Timeline) for seamless cross-filtering.

## 💡 Key Business Insights Generated
* **Demographics:** Women represent the dominant customer segment, contributing roughly 64% of total sales.
* **Platform Leader:** Amazon stands out as the highest-performing channel for revenue generation.
* **Geography:** Uttar Pradesh demonstrates the strongest regional sales presence.
* **Operations:** The order fulfillment pipeline maintains a healthy 92% successful delivery rate.
